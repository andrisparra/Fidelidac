# ParraAmp HiFi
Reproductor HiFi para Android (Kotlin + Jetpack Compose + Media3), UI inspirada en el Walkman.

## Compilar sin computadora
1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. Ve a Actions > "Build APK" (se ejecuta solo con cada push, o con "Run workflow").
3. Descarga el artefacto `ParraAmp-HiFi-debug` (zip con el APK) e instálalo.
